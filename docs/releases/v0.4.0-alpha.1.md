# PetWeaver v0.4.0-alpha.1

This is the first public preview of the PetWeaver framework migration. Fafa is
still bundled as the default example character, while runtime identity,
persona, expressions, animation assets, and live-platform events begin moving
behind reusable contracts.

## Highlights

- PetWeaver product identity, package name, Windows application ID, and
  Apache-2.0 source license.
- Validated pet-package manifest and safe external package discovery.
- Dynamic character identity, persona, expression, action, and renderer
  configuration with fallback to the built-in Fafa package.
- A documented 44-action media contract and Codex sprite-production skill.
- Normalized Bilibili and YouTube live-event adapters.
- Existing desktop interaction, physics, AI, memory, voice, media, Live2D,
  and VTube Studio integration foundations.
- 47 test files containing 288 passing tests at release time.

## Verification

- `pnpm test`: 47 files and 288 tests passed.
- `pnpm build:web`: production web build passed.
- Installer metadata reports product `PetWeaver`, version
  `0.4.0-alpha.1`.
- Packaged `app.asar` was scanned for common API-key, token, credential,
  voice-profile, and local-user-path patterns; none were found.
- The portable archive excludes logs, caches, and user-data paths; its archive
  listing was checked after compression.

## Preview limitations

- This is an alpha preview, not a stable release.
- The Windows files are **not code-signed** and may trigger SmartScreen.
- A local Microsoft Defender custom scan could not be started on the release
  workstation. The files have not been certified malware-free.
- Fafa remains the built-in example character and some UI text is still
  character-specific or Chinese.
- External unpacked pet packages are supported, but ZIP install, update, and
  uninstall workflows are not complete.
- Live2D and VTube Studio paths are integration foundations rather than a
  fully polished creator workflow.
- YouTube live support is an initial adapter and needs broader production
  testing.

## Feedback

Please report reproducible issues with the operating system version, selected
pet package, live platform, relevant settings, and sanitized logs. Do not post
API keys, cookies, voice profiles, or other credentials in public issues.
